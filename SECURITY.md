# Security Policy

## Reporting Security Issues

This project may document network services, Android internals, firmware artifacts, and reverse engineering findings.

Do not publish exploit instructions, credentials, private keys, or sensitive device-specific data in issues, commits, or pull requests.

For now, report sensitive findings privately to the repository owner.

## Scope

In scope:

- Keecker K1 preservation research.
- Documentation of exposed services and local device behavior.
- Defensive analysis of firmware, APK, ODEX/OAT, and system interfaces.

Out of scope:

- Attacks against third-party infrastructure.
- Credential harvesting.
- Bypassing access controls on devices not owned or explicitly authorized.
- Public redistribution of proprietary material before legal review.

## Current Status

Security handling is provisional. A formal disclosure process is pending.
