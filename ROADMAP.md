# Roadmap

## Phase 0 - Repository Stabilization

- Establish governance files.
- Freeze documentation taxonomy.
- Create artifact policy and artifact register.
- Record known repository hygiene issues.
- Avoid new reverse engineering work during stabilization.

## Phase 1 - Evidence Normalization

- Complete artifact hashes, sizes, source paths, and acquisition commands.
- Normalize ADB, network, APK, ODEX/OAT, and native-library evidence.
- Add reproducible acquisition procedures.

## Phase 2 - Explorer Reliability

- Fix confirmed scanner correctness issues.
- Add tests and deterministic output paths.
- Add report schemas and validation.

## Phase 3 - Reverse Engineering Dossiers

- Binder inventory.
- APK manifest and permission inventory.
- ODEX/OAT recovery workflow.
- Native library inventory.
- JNI and service mapping.

## Phase 4 - Public Project Readiness

- Select final license.
- Decide artifact redistribution policy.
- Add CI, documentation checks, issue templates, and release process.
